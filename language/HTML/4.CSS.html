beberapa cara untuk menggunakan css

  • inline
  • internal
  • external

contoh

A blue heading

A red paragraph.


<h1 style="color:blue;">A Blue Heading</h1>

<p style="color:red;">A red paragraph.</p>

internal css


<!DOCTYPE html>
<html>
<head>
<style>
body {background-color: bisque;}
h1   {color: blue;}
p    {color: red;}
</style>
</head>
<body>

<h1>This is a heading</h1>
<p>This is a paragraph.</p>

</body>
</html>

external css


<!DOCTYPE html>
<html>
<head>
<link rel="stylesheet" href="style.css">
</head>
<body>

<h1>This is a heading</h1>
<p>This is a paragraph.</p>

</body>
</html>
